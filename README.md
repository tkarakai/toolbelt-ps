# Toolbelt Processes

The processes you started across your terminals — listed, kept, restarted, focused, peeked at
and stopped. A plugin for [Toolbelt](https://github.com/tkarakai/toolbelt), and a command line
of its own: `tb ps`.

A reimplementation of [running](https://github.com/tkarakai/running) on the Toolbelt stack.

- **In Toolbelt** — a *Processes* tool with tabs for live processes, the ones you kept, and
  settings, plus a quick view from the menu bar icon.
- **`tb ps`** — the terminal UI for people, and `--json` commands for scripts and agents.

Status: not started yet — the Toolbelt plugin protocol is being proven in the
[toolbelt](https://github.com/tkarakai/toolbelt) spike first.
